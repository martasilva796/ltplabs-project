# LTP Labs – Simple Online Store

This project was developed as part of the LTP Labs frontend challenge. It is a responsive e-commerce application built with React Router and TypeScript.

## Project Overview

The application allows users to:
- Browse a list of products
- Filter products by category
- Sort products by price and title
- Search products
- View product details
- Add products to a shopping cart
- Manage cart quantity and remove items

## Pages

### Home
- Product listing fetched from DummyJSON API
- Filtering by category
- Sorting options (featured, price, title)
- Pagination system
- Navigation to product detail page

### Product Detail
- Displays full product information
- Category badge
- Add to cart functionality
- Toast feedback after adding products

### Shopping Cart
- Displays added products
- Quantity management (increase/decrease)
- Remove items
- Cart summary (subtotal, shipping, total)

## Tech Stack
- React Router
- TypeScript
- Tailwind CSS
- DummyJSON API
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

Application available at `http://localhost:5173`.
